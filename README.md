# ECO-SORT
## OBJETIVO
Desenvolver uma aplicação web interativa (formato de Quiz) focada na educação ambiental da comunidade de Olinda-PE. O sistema visa informar os cidadãos sobre os perigos do descarte incorreto de Resíduos de Equipamentos Elétricos e Eletrônicos (REEE) e mapear os Pontos de Entrega Voluntária (PEVs) disponíveis no município, utilizando diretrizes rígidas de acessibilidade (WCAG) para garantir a inclusão digital.
